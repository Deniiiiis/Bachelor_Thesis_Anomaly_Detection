# Bachelor Thesis – Anomaly Detection in Network Traffic

This repository contains the practical part of my bachelor thesis focused on anomaly detection in network traffic using unsupervised machine learning methods.

The project works with two cybersecurity datasets:

- CIC-IDS2017
- UNSW-NB15

The main goal of the project is to compare several unsupervised anomaly detection approaches and evaluate their ability to detect malicious network traffic when trained primarily on benign data.

## Current status

This project is still undergoing modifications and cleanup.

Some files, notebooks, results, comments, or README files inside the individual folders may not fully correspond to the current version of the code. The repository is being gradually reorganized and updated as the bachelor thesis progresses.

Because of that, the structure and documentation should be considered work in progress.

## Used methods

The project includes experiments with several anomaly detection models, such as:

- Isolation Forest
- One-Class SVM
- Local Outlier Factor
- Gaussian Mixture Model
- Autoencoder
- Variational Autoencoder

The models are evaluated using common classification metrics, mainly:

- Precision
- Recall
- F1-score
- Accuracy
- ROC AUC
